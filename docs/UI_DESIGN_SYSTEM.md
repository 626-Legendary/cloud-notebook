# Cloud Notebook UI/UX 设计系统

本文件是所有界面修改的主规范，涵盖登录／注册、工作台、编辑器外围、知识库、设置、后台与打印工具栏。[AGENTS.md](../AGENTS.md) 要求 UI 任务先阅读本文；[UI_TYPOGRAPHY.md](UI_TYPOGRAPHY.md) 专门维护字号、字体及文档排版边界，本文不重复字号数值。

## 1. 设计原则

- **简洁、内容、一致性优先**：界面服务于阅读、编辑和查找，装饰不抢占内容。
- 先复用已有组件，再简化交互，最后才做最小扩展。不为单个页面建立独立风格。
- 渐进呈现：常用操作可发现，低频操作进入菜单；同一任务不重复堆放多个入口。
- 正确性与可用性优先于视觉精致和动效；键盘、触屏、焦点和对比度均需考虑。
- 本文规定修改方向，不表示存量界面已全部符合。差异需先核对代码，不能据此批量替换 CSS 或改变业务行为。

## 2. 品牌与功能图标

- 产品名称为 **Cloud Notebook**，功能文案使用中文，如“知识库”“词条”“引用管理”。标签功能已移除，不新增标签入口。
- 品牌标志使用正式资产 [`src/app/icon.png`](../src/app/icon.png)，应用地址为 `/icon.png`；登录、侧栏和后台使用同一资源，保持比例与留白，不拉伸、不重绘、不加装饰滤镜。
- 功能图标使用项目锁定的 `lucide-react`，精确版本见锁文件。同一操作保持同一图标、尺寸和布局，不混用图标库或手绘功能 SVG。
- Lucide 不能替代品牌 Logo。图标按钮提供中文可访问名称；不明确的操作增加文字或悬停／焦点提示。

## 3. 语义颜色与主题

### 唯一运行来源

颜色权威实现为 [`globals.css`](../src/app/globals.css) 的 `:root`／`.dark` 变量；[`tailwind.config.ts`](../tailwind.config.ts) 仅映射这些变量，不另定数值。`next-themes` 管理浅色、深色与跟随系统，不创建第二套主题状态。

| 角色 | 当前变量 | 消费方式 |
| --- | --- | --- |
| 背景／主文字 | `--background` / `--foreground` | `hsl(var(--…))` 或对应 Tailwind 色名 |
| 中性表面／交互表面 | `--muted` / `--accent` | 同上 |
| 边框／主要操作 | `--border` / `--primary` | 同上 |
| 侧栏／页面面板／纸张 | `--sidebar-surface` / `--pages-surface` / `--paper-surface` | `var(--…)` |
| 模态框外壳 | `--modal-surface` | `var(--modal-surface)`，浅色 `#F6F5F3`，深色 `#25282D` |
| 导航选中／文字／悬停 | `--nav-selected` / `--nav-selected-text` / `--nav-hover` | `var(--…)` |
| 焦点 | `--focus-ring` | `var(--…)`，需要淡化时通过混色派生 |
| 次要／辅助文字 | `--ui-text-secondary` / `--ui-text-muted` | `var(--…)` |
| 成功／警告／危险／链接 | `--ui-text-success` / `--ui-text-warning` / `--ui-text-danger` / `--ui-text-link` | `var(--…)` |

浅／深色为同一角色的两组值，不是两套组件系统。HSL 通道变量与完整色值变量不能混用语法。本文不再维护与实际值不同的“目标色板”；改色必须在权威定义处进行，并验证所有消费者。

### 使用规则

- 中性色为基底，主要操作色保持克制；同一区域默认突出一个主操作。成功、警告和危险色只表达真实状态，不作装饰。
- 取消、返回使用次级按钮；危险入口与最终删除确认有清楚层级，不靠颜色单独解释后果。
- 组件消费语义变量，不新增散落的硬编码色值、无语义颜色类或页面专属配色。富文本内容、图片及必要第三方集成例外。
- 链接与结构化引用使用现有交互语义；失效引用应可识别但不铺满危险色。
- 深色主题检查文字、边框、悬停、禁用和弹窗对比度，不能简单反色。富文本原始颜色和打印样式不随 UI 审计改写。
- 存量 CSS 仍有局部硬编码与重复覆盖，例如 `.environment-badge` 状态变体、`.status-orphan`、`.status-grace-period` 和部分危险按钮；不能将它们视作另一份色板。后置规则也可能覆盖早期定义，需在对应 UI 任务中检查最终计算样式，按对应任务范围逐步归并。

## 4. 字体、间距与尺寸

- 字号只使用字体专项定义的语义类／变量，数值表只在 [`typography.css`](../src/app/typography.css) 维护。紧凑／标准／大号偏好与正文、标题、打印隔离，详见 [字体规范](UI_TYPOGRAPHY.md)。
- 字重和信息密度按角色保持一致；不靠极小字号解决溢出，先简化信息、换行或截断并提供完整查看。
- 间距、控件高度、圆角、边框和阴影优先复用 `globals.css` 的同类组件与 Tailwind 既有刻度。目前没有独立的 spacing／radius token 文件，不新增平行尺度。
- 留白优先于多层边框；阴影主要用于浮层，不为普通列表堆叠重阴影或装饰卡片。
- 同类按钮、输入、菜单保持相同高度与内边距。移动交互目标以易点按为准，优先接近 44×44px；紧凑控件不能依靠小图标本身承担整个点击区域。

## 5. 复用组件与交互

先检查 [`src/components/ui`](../src/components/ui)、现有 Radix 用法及全局样式。已有按钮、表单、Dialog、菜单、Popover、Toast、ScrollArea 能满足需求时不得复制另一套。

| 组件 | 规则 |
| --- | --- |
| 按钮 | 主次清楚，图标文字横向对齐；加载时防重复提交，失败保留输入 |
| 输入／搜索 | 标签与焦点清楚，区分加载、空结果、错误；输入和错误文案不能引发布局跳动 |
| 列表 | 标题为主、摘要为辅、操作靠后；长标题／别名不能撑宽容器，详情可查看完整内容 |
| 空状态 | 说明当前内容及可执行的下一步，不用大插图占据工作区 |
| Dialog | 使用 Radix 焦点管理，明确标题、关闭方式和内部滚动；编辑关闭遵守保存流程。所有模态框外壳统一使用不透明的 `var(--modal-surface)` 背景，正文使用 `hsl(var(--foreground))`，边框使用 `hsl(var(--border))` |
| Popover | 用于短预览或选择，长内容进入完整详情，不叠加词条详情弹窗 |
| Toast | 简短非阻塞，不用多个提示重复宣告同一结果；在编辑器中沿用现有通知锚点 |
| Loading／错误 | 反馈明确、可重试；不因失败丢失表单或伪装成功 |

### 工作台与编辑器外围

模态框颜色约束适用于版本历史、选择导出范围、通用表单、确认／危险操作、封面编辑／裁剪、全局搜索、登录设备、知识库词条、引用管理、导入冲突、保存冲突和退出进度。复用 `.modal-card`、`.form-dialog-content`、`.alert-content` 等现有外壳；浅深色由 `--modal-surface` 切换，禁止外壳自行使用工作区或纸张背景、硬编码白色或半透明背景。遮罩独立于内容表面；内部输入、代码块和编辑工作区保留自身语义表面。新增模态框必须提供对话框语义和可访问名称，并在浅深色下检查最终计算背景色。

- 保留文件夹 → 笔记本 → 页面层级，`isDefault` 不代表没有父行；只要父文件夹可见，子笔记本采用相同缩进。
- 桌面页面面板的拖动范围与按键约定见 [工作区布局](../README.md#工作区布局与图片记录)，宽度只在本浏览器记忆；移动抽屉不能覆盖桌面偏好，调整不能重建编辑器。
- 侧栏与页面列表共用贴边滚动风格：再次悬停、聚焦或触摸时显示，操作结束后隐藏；保留滚动位置、预留槽与边缘渐隐，高对比模式保留可见性。
- 手机宽度（≤600px）隐藏 toolbar-formatting，平板和 PC 保留；纯 CSS 响应式切换不得重建编辑器。
- 常用格式操作优先，低频操作适当收纳；手机允许导航和操作分行，不能将文字压到不可读。
- 主题切换在 App 的偏好设置中，登录／注册沿用现有 ThemeToggle；不得再增加 App 顶栏主题入口。

### 知识库与词条

- 主内容限宽 1200px 并居中，小屏使用可用宽度；标题与操作、检索与排序、结果说明、纵向列表使用一致边界，不横向溢出。
- 新建词条为 Primary；导入／导出收入现有 Radix“更多操作”菜单，桌面和移动端均保留文字入口。搜索与排序等高并排，小屏允许标题／操作换行。
- 列表为图标、名称、最多两行摘要、可选单行省略别名及修改日期；图标无装饰底色，空正文为“暂无内容”，无别名不预留空行。日期桌面置于标题右侧，手机移至标题下方。
- 使用现有 Border Token 轻量分隔、导航 Hover 背景及统一 Focus Ring，不增加卡片、阴影或持续 Selected 状态。空库提供新建入口，搜索无匹配使用独立空状态。
- 侧栏知识库作为主入口放在品牌分隔线下，垃圾箱留在底部；保留文件夹、置顶、抽屉及原有返回文档导航。
- 复用已有浅／深色纸张表面；联想菜单沿用当前约九成不透明背景与模糊效果，文字保持完全不透明，键盘选择只滚动候选区。
- 短预览标题省略、摘要最多三行，分割线下显示“查看完整词条”；短预览不呈现整篇重型编辑界面。当前 API 会按需读取目标正文生成摘要，不宣称已经提供独立摘要接口。
- 详情为单一模态框；既有词条默认阅读、新建后直接编辑、保存继续编辑，导航不叠框也不维护返回栈。行为契约统一见 [知识库规范](KNOWLEDGE_BASE.md)。
- 引用管理采用“结果 → 选择一处问题 → 选择方式 → 确认修复”；标题／底部操作固定，内容独立滚动，单一提交按钮，错误保留在当前表单。未引用词条只统计，不暗示需要删除。

### 登录、设置与后台

- 登录聚焦品牌、必要字段与主要操作，预留错误区，避免错误出现后按钮跳动。
- 设置按职责分组；后台统计用清楚的名称和数字，不堆砌多彩卡片。窄屏允许统计与操作换行。
- 破坏性操作清楚说明对象及后果、明确确认；不增加重复确认步骤。

## 6. 响应式、无障碍与验证

- 按变更影响覆盖桌面与移动端、浅／深色及相关字号档位；复杂面板可使用现有 1440／768／390／320px 布局回归。不是每次文案修改都运行全量矩阵。
- 窄屏单列或自然换行，弹窗可接近全屏并内部滚动；长内容不造成水平溢出、遮挡或不可用操作。
- 验证 Tab／Shift+Tab、Enter、Esc、方向键及关闭后焦点恢复；快捷键作用域见 [KEYBOARD_SHORTCUTS.md](KEYBOARD_SHORTCUTS.md)。
- 普通文字以 AA 对比度 4.5:1 为目标，较大文字及非文本控件按适用标准检查；状态不只靠颜色表达。该目标不代表存量页面已经全部审计通过。
- 尊重减少动态效果偏好；动画只表达状态，不用长时间弹跳、大幅位移干扰编辑。
- 检查 Loading、空、失败、禁用、Hover、Focus；文档内容、保存和打印不得受外围 UI 调整影响。
- 验证命令与隔离边界由 [tests/README.md](../tests/README.md) 维护；报告实际覆盖与未验证项。

## 7. 扩展与维护

1. 查明既有组件和 token 能否覆盖需求，避免无必要的新颜色、字体、阴影、圆角和间距。
2. 确需扩展时说明原因，先更新本文对应角色及权威 token／共享组件，再实现消费者；不要求另建规范文件。
3. CSS 冲突先追踪来源并合并职责，不能无限追加后置覆盖。现有差异只在授权范围内逐步处理。
4. 业务规则以专项文档为准；字号数值以源码 token 为准；历史实现过程和结果放 [CHANGELOG](../CHANGELOG.md)，不堆入设计规范。

知识库阅读模态框正文沿用文档字体，使用阅读容器自身内边距，不叠加编辑页的最大宽度及左右 margin；引用修复视图使用弹窗内容宽度。后台品牌与退出位于导航区域，管理员不提供逐条查看用户知识库入口。

知识库和垃圾箱共用带 ArrowLeft 返回按钮的顶部栏、1200px 内容边界及手机内边距。置顶笔记本图标与目录统一为 NotebookPen。登录品牌容器为 64px，正式图片为 48px，保持原图比例，不通过滤镜重绘线条。后台品牌、可滚动导航和退出区域分离；窄屏使用品牌／退出一行及独立横向导航一行，不能把退出放进导航滚动区。

- 代码块使用中性色背景和轻量边框。紧凑工具栏左侧显示语言，右侧复制原文，宽代码只在工具栏下方横向滚动。高亮采用浅深主题共用的语义颜色角色，纯文本保持原样。
- 编辑主滚动区负责上下 24px、水平 20px 留白，纸张最小高度为其内容区的 100%，长内容自然增长。纸张不同时使用百分比高度和 Flex 填充，正文取消视口高度下限。通知锚点占用零布局高度，保留粘性定位。
- Sidebar 保留品牌和底部垃圾箱／账号分区边界，知识库与置顶、新建之间通过间距分组，避免连续横线。
- 编辑滚动区以 `height: 0` 配合 Flex 分配获得明确高度基准，使纸张百分比最小高度在不同浏览器中稳定解析。
- Workspace 外层编辑面板包含 PageEditor 内层面板，内层必须以 `flex: 1` 占满父面板。短文档回归必须检查纸张底部距窗口底部 24px 附近，不能只比较纸张和可能同时收缩的滚动容器。
- 后台注册用户使用轻量表格，表头用次要文字，正文突出用户名，日期用说明字号，数字右对齐并用等宽数字。行使用细分隔线与共有悬停颜色，操作按钮保留可见键盘焦点。内容区宽度不超过 720px 时改为紧凑卡片。每行操作统一收纳在更多菜单，危险操作保留确认。

Workspace 的颜色层级固定为 Sidebar `#EDEEEB`、Page Panel `#F4F4F2`、Editor Workspace `#F8F8F7` 和 Document Paper `#FFFFFF`。深色主题对应 `#1C1E22`、`#22252A`、`#181A1E` 和 `#25282D`。这些颜色只能通过现有语义 Token 使用，打印与 PDF 保持独立排版。
