## 上传前确认

先预览将要加入的文件：

```bash
git status --short
git add --dry-run .
```

确认后再由仓库所有者暂存与提交：

```bash
git add .
git diff --cached --name-only
git diff --cached --stat
git commit -m "Initial import: Cloud Notebook 1.0.1112"
git push -u origin main
```

不得使用 `git add -f` 强行添加真实环境、账号、密钥或运行数据。首次上传之外，后续每次提交仍需检查暂存内容。发现真实密钥已经进入远程或历史时，应先撤销并轮换该凭据，仅删除工作区文件不足以消除历史泄露。
